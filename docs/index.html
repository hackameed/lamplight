Lamplight

measures whether your room can be read

Every camera-vitals demo is filmed in a good room.

Presage publishes what happens outside one. Same faces, same models, same cameras — the only variable is the light. Lamplight names what is wrong with the room, tells you the one physical thing to change, and refuses to invent a number it did not measure.

What we measured before building

Every claim here was tested on real hardware with @smartspectra/node-sdk 3.5.0 on Windows — not assumed from documentation.

Total darkness kills the reading entirely. But a backlit room — window behind the subject, face in shadow — still read fine, because the camera's auto-exposure compensated.

So on this hardware the failure is a cliff, not a gradient. There is no gentle slope of degrading confidence to walk a user up. We did not ship the gradient version the idea originally assumed, because the measurements did not support it.

[exposure-topup] lock collapsed image brightness (luma=6.67472 vs pre-lock 68.3133) and manual levers are exhausted — exposure reverted to AUTO. This driver has no AE lock and no gain control; auto exposure stays active during the measurement.

That line is repeatable across five runs on the target machine. The SDK attempts to lock exposure; on this camera it drives luma from 68 to 6.7 and the driver reverts to auto. A room that looks fine can still read as dark.

Why it needs to exist

From Presage's own arterial-pressure model card, by lighting condition for Fitzpatrick Type VI:

LightingNReturn rate
Ring light52653.2%
Lamp42740.4%
Window32734.2%

Human eyes adapt across an enormous range; a webcam sensor does not. You cannot tell your room is below the sensor's floor by looking at it. That gap is the product.

The one rule

The app describes light, position, and stability. It never describes the person.

  • Good: "The light is behind you. Turn it around, or move so it lights your face."
  • Never: "Your face is hard to read."
  • Never asks for, infers, or displays skin tone. It measures the signal, not the person.
  • No medical claim. It reports what a sensor measured, with the sensor's own confidence attached.

Run it

git clone https://github.com/hackameed/lamplight.git cd lamplight npm install set PHYSIOLOGY_API_KEY=your_key_here npm start # open http://localhost:4173

Requires Node 20+ and a webcam. Get a key at physiology.presagetech.com. Nothing is uploaded; the receipt is written to receipts/ on your machine.
